# 2026-10-21

## `PostMessage failed 0x80070718` 分析 + pty 合帧

- 错误码 = `ERROR_NOT_ENOUGH_QUOTA`：宿主窗口消息队列（10000 条）打满 → IPC 被静默丢弃 →
  invoke 永不 settle → 界面「点了没反应」，JS 无错误。来源 tao/wry 两处，wry 那处只在 debug 构建打印，
  所以只在 `tauri dev` 终端里看得到。
- 关键放大器：`plugin:__TAURI_CHANNEL__|fetch` 是**同步命令**（跑主线程），>1 KiB 的帧每帧
  三次主线程往返；pty 每帧固定 4 KiB，全链路无背压。
- 现场测量：dev 实例 19 小时，两个渲染进程各持续 ~25% 一个核（12904s/9519s），一个 832 MB。
- 修复：`pty.js` 输出合帧（16ms / 256KiB，终端帧前 flush）+ 看门狗记录 JS 堆大小。
  测试 323 项全过，host-checks 34/34，build 通过。细节见 `NOTES.md` §14.29。
