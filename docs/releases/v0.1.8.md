# v0.1.8

本次发布为 Windows x64，提供 NSIS `.exe` 与 MSI `.msi` 安装包。相较 v0.1.6，加入集中式模型服务、原生 Sidecar 宿主调用、截图与资源交接，并提供宿主及插件语言 API。

## 语言与界面

- 设置页支持跟随系统、简体中文与 English，主导航、设置、模型管理和托盘同步更新，无需重启插件。内置工具业务界面与第三方插件的翻译覆盖取决于各自实现。
- 插件可使用 `ctx.i18n` / `bridge.i18n` 读取语言、翻译自己的字典并订阅切换；Rust Sidecar 可通过宿主服务直接查询语言。
- 语言菜单采用项目统一样式。README 增加真实运行截图、功能说明和 [插件商店](https://github.com/wuxinoob/toolkit_plugins) 入口。

## 模型服务与思考等级

- API 连接、模型、插件授权与 API key 由宿主管理；key 存放在 Windows Credential Manager，不向插件或 Sidecar 返回。
- 提供 DeepSeek、OpenAI、Gemini、Claude、SiliconFlow 连接模板，支持 Chat Completions 与 Responses 兼容协议、目录查询及文本生成测试。
- 思考等级优先采用 API 明确声明的列表和默认值；缺失字段显示未知，手动设置不再预填三档。查询保留现有配置，显式采用才更新等级与默认值。
- 插件读取宿主允许范围并可按次覆盖默认等级；前端与 Sidecar 共用 Rust 校验和协议适配。省略参数不等于关闭模型思考，`none` 不会自动加入列表，生成成功也不证明强度参数已生效。
- 修复热键绑定输入和模型管理窗口创建路径，完善并发打开及关闭到托盘的生命周期。

## 截图与原生数据通信

- 截图支持物理像素矩形、应用名/PID/窗口 ID 定位与局部区域，提供鼠标位置及截图坐标元数据。窗口截取的是当前桌面可见像素，遮挡会进入图片。
- 原生 Sidecar 可经独立命名管道调用宿主模型、语言和资源服务，不依赖前端中转；字节传输使用独立 raw lane，原 stdin/stdout 协议继续可用。
- 同插件窗口与 Sidecar 可通过指定接收方的一次性票据交接不可变资源，分别释放引用；未领取票据有期限，不跨插件共享。
- 完善 stdio、批量上行、截图和二进制资源的容量、写入期限、取消及退出回收。

## 兼容性与发布检查

- 宿主接口为 **HOST_API 14**，信封和 Sidecar RPC 版本仍为 **1**。新增语言服务需要 `rpc:i18n`，模型调用需要 `rpc:llm` 和用户授权。
- 单个内存资源仍限 16 MiB；大文件通过 `fs` 区间读写或 Sidecar 本地 IO 处理。当前没有独立通用的 thinking 开关、思考 token 预算或完整工具调用能力。
- 发布前检查版本与锁文件一致、发布说明存在、生成接口声明最新，再运行 Windows 原生回归与 Node 测试。修复 Windows CRLF 检出时生成声明被误报过时的问题。
- 本机模拟 API、临时假凭据、真实 Windows 命名管道、文件和 PTY 回归用于自动验证；真实供应商兼容性及长期桌面运行仍需实际使用确认。
