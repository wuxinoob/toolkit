# v0.1.7

本阶段加入宿主模型服务、原生 Sidecar 直连和资源交接，完善截图及插件通信，并整理开发文档。交付 Windows x64 NSIS/MSI 安装包。

## 模型与原生插件

- 宿主管理 API 连接、模型配置、Windows Credential Manager 凭据及插件授权；前端插件和原生 Sidecar 共用模型调用运行时。
- 提供 DeepSeek、OpenAI、Gemini、Claude、SiliconFlow 连接模板，支持模型目录发现和生成测试，区分声明能力与实际生成结果。
- 支持文本及资源引用图片输入、有界文本流、取消和原生 deadline。思考等级采用宿主默认值/允许范围与插件单次覆盖；厂商兼容差异明确处理。
- Sidecar 经独立命名管道直接调用宿主；二进制数据走独立 raw lane，保留原 stdin/stdout 业务协议。

## 截图、数据与生命周期

- 截图支持桌面矩形、应用名/PID/窗口 ID 定位和局部区域；提供物理鼠标位置与截图坐标元数据。窗口目标捕获当前桌面可见像素，遮挡也会进入图片。
- 同插件窗口与 Sidecar 可通过限时、一次性、指定接收方的票据交接不可变资源；原生共享分配、独立释放引用，预算只计一次。
- stdio 溢出明确终止，顺序等待异步消费；stdin 使用有界 writer 与写入期限。批量上行按帧数和字节限制，并明确部分成功语义。
- 修复截图清理回调累积、上行端点在 Stop/renderer 恢复后无法重开；增加图像工作准入与编码输出限制。
- 修复热键输入引用错误、清空后重新捕获，以及模型管理窗口创建和并发打开的问题。
- 修复托盘模式下插件关闭监听器隐式销毁主窗口、随后被宿主重建的路径；主窗口隐藏时不触发插件退场。

## 文档与兼容性

- README 按功能、安装、开发与插件能力重新组织；同步插件手册并删除过时的文件访问评估。
- 提供字段契约、生成的 TypeScript 声明、Rust SDK 与可编译示例；两端能力发现复用版本来源。
- 宿主接口升级至 **HOST_API 13**，信封版本仍为 **1**。请按插件使用的新能力更新 manifest.api；旧版本声明会显示版本提示。
- 内存资源仍有单对象 16 MiB 上限；大型文件使用 fs 区间读取或 Sidecar 本地 IO。资源交接不跨插件，未领取票据 30 秒失效。
- 新增 [i18n 整体升级计划](../I18N-UPGRADE.md)，本版本尚未提供语言切换。

阶段验证覆盖 Node 419 项、宿主原生 94 项、截图几何、真实不读 stdin 的子进程、本机模拟 API、Windows 凭据与命名管道、Sidecar 双向交接及真实票据过期；前端生产构建与 Cargo examples 检查通过。发布工作流还会运行 PTY 生命周期/慢输出和存储并发回归。真实供应商模型兼容性及长期桌面运行仍需实际使用验证。
