# v0.1.4

修复反复执行 PTY 定时任务后界面冻结，以及 `tauri dev` 首次加载长时间等待的问题。

## 修复与精简

- PTY 同步读取、退出等待移至专用线程，异步命令不再占满 Tokio worker；完善退出、取消、尾部输出和异常清理，限制未消费输出为 8 MiB。
- Tailwind 样式扫描限定在前端 `src`，避免扫描 Cargo 构建缓存；主窗口 DOM 就绪后显示，宿主、设置页与自检按需加载。
- 启动入口共用一个窗口句柄，保留旧插件 URL 跳转和主窗口身份校验；移除诊断写入失败后的重复 IPC 请求和临时 WebView 日志参数。
- 修复诊断信标恢复后浏览器计时器未清除，以及子窗口误删主窗口诊断记录的问题。
- 统一插件 SDK 与资源释放逻辑，修复待完成资源请求、procman 停用后的定时任务及提前退出时的重试预算。
- 插件存储按文件串行更新并原子替换，避免并发写入丢失；整理架构、插件接口和故障定位文档。

## 兼容性

宿主接口为 `HOST_API 5`。截屏结果通过原始字节流返回，插件需要按当前插件 API 文档使用对应接口。PTY 命令名和 `pty:default` 权限保持兼容。

## 验证

发布前执行前端生产构建、Node 全量测试及原生 host、PTY 生命周期、存储检查；CI 和发布流程也包含原生回归。完整桌面应用的整夜定时任务仍需实际运行观察。
