# v0.1.5

本次更新扩展了插件的数据访问能力。插件可以读取剪贴板图片、按区间读取大文件，以及分块写入并提交保存。

## 插件接口

- `ctx.fs` 与 `bridge.fs` 通过原生对话框取得文件引用，支持按偏移读取和分块保存。单块最多 256 KiB，文件总大小独立于内存会话容量。写入暂存于目标目录，调用 `commit()` 后生成或替换目标。宿主按插件与窗口回收句柄。
- `ctx.binary.open()` 与 `bridge.binary.open()` 支持双向二进制 IPC。单个内存会话最多 16 MiB，主窗口与独立插件窗口使用相同接口。
- `clipboard.readImage()` 返回 PNG 字节。`clipboard.formats()` 与 `clipboard.watchFormats()` 提供格式和序号，工具可以据此识别图片并按需读取。
- `files.sha256()` 在宿主侧分块计算所选文件的 SHA-256，仅返回路径、大小和摘要。Sidecar 可以继续通过路径自行访问文件。

## 修复

- 同时限制 Sidecar 输出队列的字节数和行数，连续空行也有界。遇到超长输出行时结束进程并报告读取错误。
- 将原始字节请求交给后台线程处理，并纳入 IPC 在途请求的诊断记录。

## 兼容性

宿主接口为 `HOST_API 7`，通信信封版本保持为 1。使用新文件接口的插件需声明 `rpc:fs`。拖放继续提供路径，文件引用由原生对话框发放。现有插件接口见[插件手册](https://github.com/wuxinoob/toolkit/blob/v0.1.5/docs/plugin-dev/README.md)。
